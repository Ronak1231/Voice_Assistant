# 🎙️ Jarvis AI Voice Assistant

An advanced AI-powered Voice Assistant built using Python, Speech Recognition, Text-to-Speech, and Generative AI APIs.  
This assistant can listen to user commands, respond intelligently, automate tasks, fetch news, play music, and much more.

---

## 🚀 Features

- 🎤 Speech Recognition
- 🔊 Text-to-Speech Responses
- 🤖 AI-Powered Conversations using Gemini API
- 📰 Latest News Fetching
- 🎵 Music Playback Support
- 🌐 Web Search Automation
- 📂 Open Applications & Websites
- ⏰ Time & Date Information
- 🧠 Smart Command Processing
- 💬 Interactive Voice Communication
- 🖥️ Streamlit-based User Interface
- ⚡ Fast and Lightweight Assistant

## ⚙️ Installation

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/Ronak1231/Voice_Assistant.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd Voice_Assistant
```

### 3️⃣ Create Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate Virtual Environment

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / Mac

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 🔑 Environment Variables

Create a `.env` file in the root directory and add your API keys:

```env
GEMINI_API_KEY=your_api_key_here
NEWS_API_KEY=your_news_api_key
```

---

## ▶️ Run the Project

```bash
python main.py
```

OR

```bash
streamlit run app.py
```
